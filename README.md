# react-ztext

ZDog React 3D text via [Zfont](https://jaames.github.io/zfont/).

## Setup

```bash
npm install
```

## Storybook

```bash
npm run storybook
```

Open [http://localhost:6006](http://localhost:6006) to browse the `Components/ZText` stories.

## Dev app

```bash
npm run dev
```

## Build

```bash
npm run build
npm run build-storybook
```
